# Task Mapping operating rules

Use current live source and the decision register as evidence. Preserve all interfaces and unrelated verticals. Four permanent vertical branches only: preinspection, installation, delivery, service; main is the integration baseline. Do not deploy from a vertical branch. Do not add deployment automation without source fingerprint checking, backup, tests, concurrency control and readback. Do not manage Pre-Inspection inspector-owned custom fields 854, 852, 853 or 860. Preserve the approved notification template. Distinguish cached results from live verification. Never commit credentials or customer exports. Automated Calendar changes never notify attendees (always "Don't send"): write only with CalendarApp setters that send no guest updates, pass sendUpdates=none on any Calendar API write, and never add or remove guests; tests/calendar_no_notifications.test.js enforces this.
